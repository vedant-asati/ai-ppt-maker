# Examples & Showcase Presentations

This directory contains reference presentations, master blueprint plans, and presentation assets generated by `ppt_maker`.

Every presentation is compiled into both **text-selectable vector PDFs** (via Playwright headless Chromium) and **native, fully editable PowerPoint (`.pptx`) decks** (via `python-pptx` with background plate isolation).
